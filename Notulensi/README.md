# 📋 Sistem Notulensi & Laporan Perkembangan Bulanan

Folder ini digunakan untuk melacak perkembangan proyek **Juragan by Anak Bawang** secara berkala (mingguan dan bulanan).

* **[TEMPLATE.md](file:///d:/Dokumen/02_Kerja_Profesional/Juragan%20by%20Anak%20Bawang/Notulensi/TEMPLATE.md)**: Format dasar untuk notulensi bulanan baru.
* **[2026/08_Agustus/notul_bulanan.md](file:///d:/Dokumen/02_Kerja_Profesional/Juragan%20by%20Anak%20Bawang/Notulensi/2026/08_Agustus/notul_bulanan.md)**: Dokumen aktif untuk bulan Agustus 2026.

## ⚙️ Alur Kerja (Workflow)
1. **Pembaruan Mingguan**:
   * Setiap minggu, tuliskan pencapaian (achievements), kendala (obstacles), atau catatan keputusan penting pada minggu yang sesuai.
   * Anda bisa meminta AI untuk merangkum perkembangan ini secara berkala berdasarkan pekerjaan yang sedang dilakukan.
2. **Evaluasi Akhir Bulan (Next Plan)**:
   * Di akhir bulan, isi bagian **Ringkasan Eksekutif** dan tentukan prioritas untuk bulan berikutnya di bagian **Rencana Bulan Depan (Next Month Plan)**.
3. **Membuat Bulan Baru**:
   * Buat folder tahun jika belum ada (misal: `2026`).
   * Buat folder bulan di dalam folder tahun tersebut dengan format `MM_NamaBulan` (misal: `08_Agustus`).
   * Salin file `TEMPLATE.md` ke dalam folder bulan baru tersebut dengan nama `notul_bulanan.md`.
   * Sesuaikan rentang tanggal untuk setiap minggu pada bulan tersebut.
