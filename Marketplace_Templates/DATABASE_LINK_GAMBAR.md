## 🛠️ Catatan Penting Mengenai URL

1. **Perbaikan Parameter Query**:
   TikTok Seller Center sering mendownload/mengexport URL dengan format `from=1432613627width=1152`. Pastikan **selalu menyisipkan tanda `&`** sebelum `width=` sehingga menjadi `from=1432613627&width=1152` agar sistem validasi gambar Excel tidak mengalami error / broken link.
2. **Cara Generate Ulang Excel Template**:
   Jika terjadi perubahan data atau ingin mengisi ulang template, cukup jalankan skrip Python:
   ```bash
   python Marketplace_Templates/fix_templates.py
   python Marketplace_Templates/audit_excel.py
   ```
